# clean

Step one of the pipeline: turn a messy edge or trade table into a flow frame, and get a report of every change. Available as `nv.clean`, `nv.CleaningReport`, `nv.CleaningStep` and `nv.MirrorStats`. The bundled FAOSTAT sample in its raw bulk-file layout, `nv.datasets.faostat.raw_sample()`, is a ready-made messy input to try it on.
