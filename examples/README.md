# Examples

The example notebooks live in [`docs/gallery/`](../docs/gallery/) so that the documentation site renders them directly. Each one runs offline on the sample bundled with the package.

- [`any-networkx-graph.ipynb`](../docs/gallery/any-networkx-graph.ipynb): the plots on any NetworkX graph: colour, size, communities, weighted, directed, multi and bipartite graphs, focus and ego views, labels, large graphs, `plot.auto`, and animation over time.
- [`faostat-pipeline.ipynb`](../docs/gallery/faostat-pipeline.ipynb): raw FAOSTAT rows through `clean`, `build_graph` and the plots: the cleaning report, mirror flows, ranking by change, one country's exports and imports, and an animated flow map.
- [`wheat-2022-shock.ipynb`](../docs/gallery/wheat-2022-shock.ipynb): the 2022 wheat trade shock, reporter perspectives, exporters ranked by change, supplier concentration, Sankey diagram, flow map and networks.
- [`community-structure.ipynb`](../docs/gallery/community-structure.ipynb): Louvain communities, modularity, community graph and adjacency matrix, stability across seeds, comparison with greedy modularity.
- [`power-law-vs-lognormal.ipynb`](../docs/gallery/power-law-vs-lognormal.ipynb): power-law tail fits for degree and strength, with likelihood-ratio tests against lognormal and exponential tails.

Rendered versions: <https://tysonjohnsondev.github.io/netviz_tools/gallery/>
